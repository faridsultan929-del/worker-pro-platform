🧪 Hardness Testing Methods

🔴 Rockwell

Метод определения твёрдости по глубине остаточного или общего внедрения индентора.

🔵 Brinell

Метод определения твёрдости по размеру отпечатка после приложения нагрузки.

🟢 Vickers

Метод с использованием алмазного индентора и измерения диагоналей отпечатка.

🟡 Microhardness

Измерение твёрдости небольших участков, тонких слоёв и отдельных зон материала.

⚙️ Surface Hardness

Контроль твёрдости поверхностного слоя промышленной детали.

🔥 Heat Treatment Control

Проверка изменения твёрдости после термической обработки.

📐 Main Parameters

Hardness Value

Значение твёрдости образца по выбранной системе измерения.

Test Load

Испытательная нагрузка, применяемая к образцу.

Indenter

Тип и характеристики индентора, используемого при испытании.

Indentation

Геометрия и размер отпечатка после испытания.

Surface Condition

Состояние поверхности образца перед измерением.

Test Repeatability

Стабильность результатов повторных измерений.
