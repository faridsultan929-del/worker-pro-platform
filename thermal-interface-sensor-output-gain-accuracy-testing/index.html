TESTING №269

Thermal Interface Sensor Output Gain Accuracy Testing

Проверка точности коэффициента усиления выходного сигнала температурного датчика относительно установленного эталонного Gain.

Испытание определяет измеренный Gain, абсолютную ошибку, относительную ошибку, отклонение от Reference Gain и соответствие заданному пределу точности.

Рабочий процесс

1. Define Reference

Установить эталонное значение Gain.

2. Verify Calibration

Проверить состояние калибровки датчика.

3. Apply Input

Создать контролируемое изменение входного параметра.

4. Measure Output

Измерить соответствующее изменение выходного сигнала.

5. Calculate Gain

Определить фактический коэффициент усиления.

6. Compare Reference

Сравнить измеренный Gain с эталонным.

7. Calculate Error

Рассчитать абсолютную и относительную ошибку.

8. Repeat Measurement

Проверить результат повторным измерением.

9. Evaluate Accuracy

Сравнить ошибку с установленным пределом.

10. Technical Report

Сформировать технический отчёт испытания.

Gain Error

Gain Error = Measured Gain − Reference Gain.

Relative Error

Относительная ошибка показывает величину отклонения от эталонного Gain в процентах.

Accuracy

В демонстрационном расчёте Accuracy представлена как 100% минус абсолютная относительная ошибка.

Repeat Difference

Разница между основным измеренным Gain и повторным измерением.
