TESTING №263

Thermal Interface Sensor Output Offset Testing

Проверка выходного смещения температурного датчика относительно заданного эталонного выходного значения при определённом входном состоянии.

Испытание позволяет определить положительный или отрицательный Output Offset, абсолютную ошибку, относительное отклонение, повторяемость и стабильность смещения.

Рабочий процесс

1. Define Reference

Определить эталонный выходной сигнал.

2. Set Input Condition

Установить заданную температуру или другое входное состояние.

3. Measure Output

Получить фактический выход датчика.

4. Calculate Offset

Рассчитать разницу между измеренным и эталонным выходом.

5. Calculate Error

Определить абсолютную величину смещения.

6. Calculate Deviation

Определить относительное отклонение в процентах.

7. Repeat Measurement

Проверить повторяемость результата.

8. Compare Previous

Сравнить текущее смещение с предыдущим испытанием.

9. Evaluate Stability

Проверить изменение Offset во времени или после цикла.

10. Final Report

Сформировать технический отчёт.

Output Offset

Разница между фактическим выходом датчика и заданным эталонным выходным значением.

Offset Error

Абсолютная величина выходного смещения относительно эталона.

Offset Deviation

Относительное отклонение смещения от эталонного выхода, выраженное в процентах.

Zero-Point Shift

Изменение выходного значения датчика в заданной точке после воздействия или повторного испытания.
