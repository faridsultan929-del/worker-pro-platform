Что проверяется

Reference Point

Эталонное значение, с которым сравнивается датчик.

Measured Value

Фактическое показание проверяемого датчика.

Measurement Error

Разница между измеренным и эталонным значением.

Tolerance

Допустимое отклонение, установленное процедурой.

Calibration Status

Проверка актуальности калибровки.

Verification Result

PASS, REVIEW или FAIL.

Калибровочные точки

Low Point

Нижняя точка рабочего диапазона.

Mid Point

Средняя точка рабочего диапазона.

High Point

Верхняя точка рабочего диапазона.

Multi-Point

Проверка нескольких точек для оценки поведения датчика по диапазону.

Результаты проверки

PASS

Абсолютная ошибка находится в пределах установленного допуска.

REVIEW

Результат требует дополнительной оценки, например при приближении к пределу или проблемах с документацией.

FAIL

Ошибка превышает установленный допуск или калибровочный статус неприемлем.

Certificate

Калибровочный сертификат должен быть действительным и прослеживаемым.
