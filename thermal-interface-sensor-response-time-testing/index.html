Thermal Interface Sensor Response Time Testing

Раздел предназначен для определения того, насколько быстро датчик реагирует на изменение температуры или другого контролируемого теплового параметра.

Основной принцип: изменение входного воздействия → изменение сигнала датчика → измерение времени отклика.

Что измеряется

Response Time

Общее время реакции датчика на изменение входного параметра.

T50

Время достижения примерно 50% изменения сигнала.

T90

Время достижения примерно 90% изменения сигнала.

Rise Time

Время реакции при увеличении температуры.

Fall Time

Время реакции при уменьшении температуры.

Signal Delay

Задержка между изменением физического параметра и реакцией системы.

Результаты

PASS

T90 находится в пределах установленного максимального времени отклика.

REVIEW

Результат близок к пределу и требует дополнительной проверки.

FAIL

Время реакции превышает установленный предел.
