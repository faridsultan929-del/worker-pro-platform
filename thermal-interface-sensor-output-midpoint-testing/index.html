TESTING №262

Thermal Interface Sensor Output Midpoint Testing

Проверка средней точки выходного диапазона температурного датчика. Output Midpoint определяется как среднее значение между минимальным и максимальным выходным сигналом.

Испытание позволяет сравнить фактическую среднюю точку с заданной номинальной средней точкой, определить отклонение, относительную ошибку и стабильность результата при повторных измерениях.

Рабочий процесс

1. Define Input Range

Определить минимальную и максимальную входную температуру.

2. Define Output Limits

Определить минимальный и максимальный выход датчика.

3. Determine Reference Midpoint

Рассчитать номинальную среднюю точку.

4. Measure Outputs

Получить фактические минимальное и максимальное значения.

5. Calculate Midpoint

Рассчитать среднее значение фактических выходных границ.

6. Compare Values

Сравнить фактическую и номинальную средние точки.

7. Calculate Error

Определить абсолютное и относительное отклонение.

8. Repeat Test

Проверить воспроизводимость средней точки.

9. Check Stability

Оценить изменение средней точки между испытаниями.

10. Final Report

Сформировать технический отчёт испытания.

Output Midpoint

Среднее арифметическое минимального и максимального выходного сигнала датчика.

Midpoint Error

Абсолютная разница между измеренной и номинальной средней точкой.

Midpoint Deviation

Относительное отклонение средней точки от заданного значения в процентах.

Output Symmetry

Показывает, насколько фактическая средняя точка расположена относительно центра заданного выходного диапазона.
