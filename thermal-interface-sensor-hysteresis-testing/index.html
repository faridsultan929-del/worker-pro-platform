Thermal Interface Sensor Hysteresis Testing

Раздел предназначен для определения гистерезиса датчика: разницы показаний при прохождении одного и того же диапазона температур в направлении нагрева и охлаждения.

Основная идея: нагрев → измерение → охлаждение → повторное измерение → сравнение.

Что проверяется

Heating Response

Показания датчика при повышении температуры.

Cooling Response

Показания датчика при снижении температуры.

Hysteresis Error

Разница показаний при одинаковой температуре в разных направлениях.

Repeatability

Стабильность результата при повторных циклах.

Cycle Difference

Изменение гистерезиса между последовательными циклами.

Acceptance Limit

Сравнение измеренного значения с допустимым пределом.

Interpretation

PASS

Разница между показаниями при нагреве и охлаждении не превышает установленный предел.

REVIEW

Гистерезис находится близко к пределу и требует дополнительного цикла или проверки.

FAIL

Измеренный гистерезис превышает установленный критерий приемки.

Repeatability

Повторные температурные циклы помогают определить, является ли эффект стабильным.
