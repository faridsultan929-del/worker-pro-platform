⚡ Eddy Current Testing

Вихретоковый неразрушающий контроль — метод исследования электропроводящих материалов с использованием переменного электромагнитного поля. Метод применяется для обнаружения поверхностных и близких к поверхности дефектов, контроля труб, теплообменников, деталей и оценки электропроводности.
