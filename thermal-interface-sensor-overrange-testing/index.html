Thermal Interface Sensor Overrange Testing

Проверка поведения температурного датчика, когда измеряемый параметр выходит за установленный рабочий диапазон.

Тест позволяет определить момент выхода за диапазон, корректность индикации Overrange, насыщение или ограничение выходного сигнала, величину превышения и поведение датчика при возвращении значения в допустимый диапазон.

Рабочий процесс

1. Define Range

Определить минимальный и максимальный диапазон измерения.

2. Identify Output

Определить нормальный выходной сигнал датчика.

3. Establish Limit

Зафиксировать верхний или нижний предел диапазона.

4. Apply Overrange

Контролируемо вывести измеряемый параметр за предел диапазона.

5. Record Output

Записать фактический выходной сигнал.

6. Check Indication

Проверить корректность состояния Overrange.

7. Check Saturation

Проверить ограничение или насыщение выходного сигнала.

8. Return to Range

Вернуть измеряемое значение в допустимый диапазон.

9. Verify Recovery

Проверить корректность работы после выхода за диапазон.

10. Technical Report

Сформировать технический отчёт.

Overrange Detection

Проверяется момент, когда измеряемая температура выходит за пределы заданного диапазона.

Output Saturation

Проверяется, ограничивается ли выходной сигнал ожидаемым максимальным или минимальным значением.

Return-to-Range

После выхода за диапазон датчик должен корректно работать при возвращении измеряемого значения в рабочую область.

Overrange Indication

Проверяется корректность специального состояния, сигнала или сообщения о выходе измерения за диапазон.
