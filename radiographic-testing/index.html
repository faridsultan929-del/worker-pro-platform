🧪 Radiographic Testing Methods

📸 X-Ray Inspection

Получение рентгеновских изображений для проверки внутренней структуры деталей.

🎞️ Film Radiography

Использование радиографической плёнки для фиксации изображения изделия.

💻 Digital Radiography

Цифровая регистрация изображений и хранение результатов контроля.

🔩 Weld Inspection

Контроль сварных соединений для выявления возможных внутренних несплошностей.

🧩 Component Inspection

Проверка отливок, металлических компонентов и отдельных промышленных деталей.

📄 Digital Test Report

Формирование демонстрационного отчёта с результатами радиографического контроля.
