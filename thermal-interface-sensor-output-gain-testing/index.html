TESTING №264

Thermal Interface Sensor Output Gain Testing

Проверка коэффициента усиления выходного сигнала температурного датчика относительно изменения входного параметра.

Испытание определяет фактический Output Gain, сравнивает его с эталонным коэффициентом, рассчитывает ошибку Gain, относительное отклонение, повторяемость и стабильность.

Рабочий процесс

1. Define Input Range

Определить начальное и конечное входные значения.

2. Measure Initial Output

Зафиксировать выходной сигнал в начальной точке.

3. Measure Final Output

Зафиксировать выходной сигнал в конечной точке.

4. Calculate Input Change

Определить изменение входного параметра.

5. Calculate Output Change

Определить изменение выходного сигнала.

6. Calculate Gain

Рассчитать отношение изменения выхода к изменению входа.

7. Compare Reference

Сравнить измеренный Gain с эталонным значением.

8. Repeat Test

Проверить воспроизводимость коэффициента.

9. Evaluate Stability

Сравнить текущий Gain с предыдущими измерениями.

10. Final Report

Сформировать технический отчёт.

Output Gain

Отношение изменения выходного сигнала к изменению входного параметра в заданном испытательном диапазоне.

Gain Error

Абсолютная разница между измеренным и заданным коэффициентом Gain.

Gain Deviation

Относительное отклонение измеренного Gain от эталонного значения, выраженное в процентах.

Gain Stability

Способность датчика сохранять близкий коэффициент усиления при повторных измерениях и изменении условий.
