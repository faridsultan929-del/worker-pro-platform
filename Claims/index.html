Как будет работать Claims

1. Покупатель создаёт претензию и указывает номер заказа.

2. Добавляет описание проблемы, фотографии и документы.

3. Поставщик получает уведомление о претензии.

4. Стороны обсуждают решение через систему сообщений.

5. При необходимости претензия может перейти в раздел Disputes.

6. После решения претензия закрывается.

Связь с другими разделами

Claims будет связан с Orders, Delivery, Documents, Messages, Disputes, Returns и Support.

Сейчас это демонстрационная версия интерфейса. Реальная система претензий будет подключена после создания серверной части WORKER PRO.
