📐 Main Test Parameters

Compressive Strength

Определение способности материала выдерживать сжимающую нагрузку.

Maximum Load

Максимальная нагрузка, зарегистрированная во время испытания.

Deformation

Изменение размеров образца под действием нагрузки.

Compressive Stress

Расчёт напряжения в испытываемом образце.

Strain

Относительная деформация материала.

Test Speed

Скорость приложения нагрузки во время испытания.
