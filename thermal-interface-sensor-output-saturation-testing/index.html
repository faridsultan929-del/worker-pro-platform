TESTING №257

Thermal Interface Sensor Output Saturation Testing

Проверка момента и поведения выходного сигнала температурного датчика, когда его выход достигает установленного максимального или минимального значения и дальнейшее изменение входной температуры уже не приводит к пропорциональному изменению выхода.

Тест помогает определить уровень насыщения, точку начала насыщения, величину отклонения и корректность поведения выходного сигнала в предельной области.

Рабочий процесс

1. Define Input Range

Определить диапазон входной температуры.

2. Define Output Range

Определить допустимый выходной диапазон датчика.

3. Establish Reference

Получить исходные значения до достижения предельной области.

4. Increase Input

Постепенно увеличить входную температуру.

5. Record Output

Записывать выходной сигнал на каждой точке.

6. Identify Saturation

Определить точку, где выход перестаёт следовать входному изменению.

7. Check Limit

Сравнить выход с установленным пределом.

8. Calculate Error

Рассчитать отклонение от ожидаемого выходного значения.

9. Return Input

Вернуть входной параметр в нормальный диапазон.

10. Technical Report

Сформировать технический отчёт.

Saturation Point

Температурная или входная точка, после которой выходной сигнал начинает ограничиваться установленным пределом.

Output Limit

Максимальное или минимальное значение, которое способен выдать измерительный канал в установленной конфигурации.

Saturation Error

Разница между ожидаемым и фактически измеренным выходным сигналом в области насыщения.

Post-Saturation Behavior

Проверка поведения выхода после возвращения входного параметра из предельной области.
