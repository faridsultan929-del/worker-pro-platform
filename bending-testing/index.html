📐 Main Test Parameters

Bending Strength

Определение способности материала выдерживать нагрузку при изгибе.

Flexural Strength

Определение предельной прочности материала при изгибающей нагрузке.

Maximum Load

Максимальная нагрузка, зарегистрированная во время демонстрационного испытания.

Deflection

Измерение перемещения образца под действием нагрузки.

Strain

Относительная деформация материала во время испытания.

Test Speed

Скорость приложения нагрузки к образцу.
