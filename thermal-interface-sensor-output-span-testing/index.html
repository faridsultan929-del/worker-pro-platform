TESTING №261

Thermal Interface Sensor Output Span Testing

Проверка ширины выходного диапазона температурного датчика: разницы между максимальным и минимальным фактически полученным выходным сигналом.

Испытание позволяет определить фактический Output Span, сравнить его с заданным Span, определить относительную ошибку, коэффициент использования диапазона и стабильность ширины выходного сигнала при повторных измерениях.

Рабочий процесс

1. Define Input Range

Определить минимальную и максимальную входную температуру.

2. Define Reference Span

Установить требуемую ширину выходного диапазона.

3. Measure Minimum

Зафиксировать минимальный выходной сигнал.

4. Measure Maximum

Зафиксировать максимальный выходной сигнал.

5. Calculate Span

Вычислить разницу между максимальным и минимальным выходом.

6. Compare Reference

Сравнить фактический Span с эталонным.

7. Calculate Deviation

Определить абсолютное и относительное отклонение.

8. Repeat Test

Проверить воспроизводимость ширины диапазона.

9. Check Stability

Оценить изменение Span между последовательными испытаниями.

10. Final Report

Сформировать технический отчёт.

Output Span

Разница между максимальным и минимальным выходным сигналом датчика в пределах конкретного испытательного диапазона.

Span Error

Разница между измеренной и эталонной шириной выходного диапазона.

Span Deviation

Относительное отклонение измеренного Span от заданного эталонного значения, выраженное в процентах.

Span Stability

Способность датчика сохранять близкую ширину выходного диапазона при повторных измерениях и одинаковых условиях.
