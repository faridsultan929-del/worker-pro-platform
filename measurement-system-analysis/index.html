📏 Measurement System Analysis

MSA — анализ измерительной системы — помогает оценивать качество измерений и пригодность измерительной системы для производственного контроля. Анализ может учитывать точность, смещение, повторяемость, воспроизводимость, стабильность и Gauge R&R.
