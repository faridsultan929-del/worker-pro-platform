TESTING #248

Thermal Interface Sensor Linearity Testing

Thermal Interface Sensor Linearity Testing evaluates how closely a sensor's measured values follow the reference values across its operating range.

The test identifies measurement deviation, maximum linearity error, average absolute error, regression slope, intercept and R².

The objective is to determine whether the sensor provides a predictable and sufficiently linear response throughout the specified measurement range.

What Is Tested?

Reference Points

Known reference temperatures distributed across the operating range.

Measured Values

Actual sensor readings corresponding to each reference point.

Deviation

Difference between measured and reference values.

Linearity Error

Maximum deviation from the expected linear relationship.

Regression

Linear regression slope and intercept across the tested range.

R²

Coefficient of determination describing the quality of the linear fit.

Testing Methods

Multi-Point Comparison

Compare sensor readings at several reference points.

Linear Regression

Determine slope, intercept and R² across the operating range.

End-Point Method

Evaluate deviation relative to the defined end-point line.

Best-Fit Method

Evaluate maximum deviation from the calculated best-fit line.

Full-Scale Error

Express maximum deviation as a percentage of measurement span.

Repeated Linearity Test

Repeat measurements to verify consistency of the linear response.

Quality Decision

PASS

Linearity error is within the defined full-scale tolerance.

REVIEW

Linearity is close to the acceptance limit and requires technical review.

FAIL

Linearity error exceeds the defined acceptance tolerance.
