TESTING #217

Thermal Interface Resistance Testing

Испытание теплового сопротивления на границе контакта между двумя материалами или поверхностями.

Метод используется для оценки способности тепла проходить через контактную область и для определения влияния давления, шероховатости, материала интерфейса, температуры и контактных условий.
