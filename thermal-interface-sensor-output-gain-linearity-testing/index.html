TESTING №268

Thermal Interface Sensor Output Gain Linearity Testing

Проверка линейности коэффициента усиления выходного сигнала температурного датчика по нескольким измерительным точкам.

Испытание сравнивает измеренный Gain с эталонным Gain, определяет отклонение, максимальную ошибку, среднюю ошибку, наклон характеристики и коэффициент R².

Рабочий процесс

1. Define Range

Определить рабочий диапазон входного параметра.

2. Select Points

Выбрать несколько измерительных точек.

3. Apply Input

Последовательно подать контролируемые входные значения.

4. Measure Output

Зафиксировать выходной сигнал датчика.

5. Calculate Gain

Определить Gain для каждой точки.

6. Compare Reference

Сравнить измеренные значения с Reference Gain.

7. Regression

Рассчитать линейную зависимость и R².

8. Determine Error

Определить максимальное и среднее отклонение.

9. Evaluate Limit

Сравнить результат с установленным пределом линейности.

10. Technical Report

Сформировать технический отчёт.

Gain Error

Разница между измеренным коэффициентом усиления и эталонным Gain.

Linearity Error

Максимальное отклонение измеренной характеристики от выбранной линейной зависимости.

R²

Коэффициент детерминации, показывающий соответствие данных линейной регрессионной модели.

Linearity %FS

Максимальная ошибка, выраженная относительно заданного полного диапазона выходного сигнала.
