TESTING №260

Thermal Interface Sensor Output Range Testing

Проверка фактического диапазона выходного сигнала температурного датчика в заданных условиях эксплуатации.

Испытание определяет минимальный и максимальный доступный выход, ширину диапазона, рабочую область, симметрию диапазона и соответствие заданной спецификации. Основной объект проверки — полный output range, а не только отдельный верхний или нижний лимит.

Рабочий процесс

1. Define Input Range

Установить минимальную и максимальную входную температуру.

2. Define Output Specification

Зафиксировать допустимый выходной диапазон.

3. Establish Minimum Point

Измерить выход при минимальном входном значении.

4. Establish Maximum Point

Измерить выход при максимальном входном значении.

5. Sweep Full Range

Проверить промежуточные точки диапазона.

6. Calculate Span

Рассчитать фактическую ширину выходного диапазона.

7. Compare Specification

Сравнить фактический диапазон со спецификацией.

8. Check Resolution

Проверить способность системы различать изменения выхода.

9. Repeat Measurement

Повторить измерения для проверки стабильности диапазона.

10. Final Report

Сформировать технический отчёт.

Output Span

Разница между максимальным и минимальным фактически измеренным выходным сигналом.

Measured Range

Фактический диапазон выходных значений, полученный во время испытания.

Range Error

Разница между заданной и измеренной шириной выходного диапазона.

Range Coverage

Степень соответствия фактического выходного диапазона требуемому диапазону датчика.
