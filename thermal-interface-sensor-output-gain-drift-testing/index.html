TESTING №267

Thermal Interface Sensor Output Gain Drift Testing

Проверка изменения коэффициента усиления выходного сигнала температурного датчика относительно начального или эталонного значения в течение заданного периода.

Испытание определяет величину положительного или отрицательного дрейфа Gain, скорость дрейфа, максимальное отклонение, накопленный дрейф и соответствие установленному Drift Limit.

Рабочий процесс

1. Define Reference

Определить эталонный или начальный Gain.

2. Initial Measurement

Зафиксировать исходный коэффициент усиления.

3. Observation Period

Определить продолжительность испытания.

4. Periodic Measurements

Проводить повторные измерения Gain.

5. Determine Maximum

Определить максимальное значение Gain.

6. Determine Minimum

Определить минимальное значение Gain.

7. Calculate Drift

Рассчитать изменение между начальным и конечным Gain.

8. Calculate Drift Rate

Определить скорость изменения Gain во времени.

9. Compare Drift Limit

Сравнить максимальное отклонение с допустимым пределом.

10. Final Report

Сформировать технический отчёт по результатам.
