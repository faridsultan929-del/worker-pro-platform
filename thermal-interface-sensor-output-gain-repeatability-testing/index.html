Thermal Interface Sensor Output Gain Repeatability Testing

Проверка повторяемости коэффициента усиления выходного сигнала температурного датчика при повторных измерениях в одинаковых или контролируемых условиях.

Испытание определяет средний Gain, минимальный и максимальный Gain, диапазон повторяемости, стандартное отклонение, Repeatability Error и процент повторяемости.

Рабочий процесс

1. Define Test Conditions

Зафиксировать температуру, диапазон и условия измерения.

2. Reference Gain

Определить эталонный коэффициент усиления.

3. First Measurement

Получить первое значение Gain.

4. Repeated Measurements

Выполнить несколько повторных измерений.

5. Calculate Average

Рассчитать среднее значение Gain.

6. Determine Range

Найти разницу между максимальным и минимальным Gain.

7. Calculate Deviation

Определить отклонение результатов от среднего значения.

8. Calculate Repeatability

Рассчитать ошибку и процент повторяемости.

9. Compare Limit

Сравнить результат с установленным пределом.

10. Final Report

Сформировать технический отчёт.

Average Gain

Среднее значение коэффициента усиления по всем повторным измерениям.

Gain Range

Разница между максимальным и минимальным измеренным Gain.

Standard Deviation

Статистическая оценка разброса повторных значений Gain относительно среднего.

Repeatability Error

Максимальная разница между повторными измерениями в заданных условиях.
