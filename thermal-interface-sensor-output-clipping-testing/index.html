TESTING №258

Thermal Interface Sensor Output Clipping Testing

Проверка обрезания выходного сигнала температурного датчика при достижении верхнего или нижнего предела измерительного или электронного канала.

Тест позволяет определить фактическую область clipping, величину потерянного диапазона, ошибку относительно ожидаемого сигнала и поведение выхода после возврата входной температуры в рабочий диапазон.

Рабочий процесс

1. Define Output Range

Установить верхний и нижний допустимые пределы выхода.

2. Establish Reference

Получить исходную характеристику датчика.

3. Increase Input

Постепенно изменить входную температуру.

4. Monitor Output

Наблюдать изменение выходного сигнала.

5. Detect Clipping

Определить момент, когда выход перестаёт изменяться пропорционально входу.

6. Record Limits

Зафиксировать фактический верхний или нижний предел.

7. Calculate Error

Сравнить ожидаемый и фактический выход.

8. Return Input

Вернуть входной параметр в рабочий диапазон.

9. Verify Recovery

Проверить выход после выхода из clipping-состояния.

10. Technical Report

Сформировать технический отчёт испытания.

Output Clipping

Состояние, при котором дальнейшее изменение входного параметра не отражается соответствующим изменением выходного сигнала из-за достижения установленного предела.

Upper Clipping

Ограничение выходного сигнала сверху при достижении максимального доступного уровня.

Lower Clipping

Ограничение выходного сигнала снизу при достижении минимального доступного уровня.

Lost Output Range

Часть ожидаемого выходного диапазона, которая не может быть представлена датчиком после достижения clipping-предела.
