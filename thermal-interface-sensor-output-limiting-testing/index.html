TESTING №259

Thermal Interface Sensor Output Limiting Testing

Проверка работы заданных ограничителей выходного сигнала температурного датчика. Испытание определяет, насколько точно система удерживает выход внутри установленного верхнего и нижнего предела.

В отличие от проверки clipping, здесь основной объект контроля — именно функция ограничения выходного диапазона: величина лимита, точность его срабатывания, устойчивость удержания и корректность возврата в рабочую область.

Рабочий процесс

1. Define Limits

Установить верхний и нижний пределы выходного сигнала.

2. Verify Reference

Проверить исходную характеристику датчика.

3. Apply Input

Изменять входную температуру по заданной программе.

4. Detect Activation

Определить момент срабатывания ограничения.

5. Measure Output

Зафиксировать фактический ограниченный сигнал.

6. Calculate Limit Error

Сравнить фактическое и заданное значение ограничения.

7. Check Response

Оценить время реакции ограничителя.

8. Check Hysteresis

Проверить поведение при увеличении и уменьшении входа.

9. Release Limit

Вернуть входной параметр в нормальную область.

10. Final Report

Сформировать технический отчёт испытания.

Output Limit

Заданное максимальное или минимальное значение, выше или ниже которого выходной сигнал не должен переходить в установленной конфигурации.

Limit Activation

Момент, когда система начинает применять заданное ограничение к выходному сигналу.

Limit Error

Разница между фактическим уровнем ограниченного выхода и заданным значением лимита.

Limit Hysteresis

Разница между условиями срабатывания и освобождения ограничения при изменении входного параметра в противоположных направлениях.
